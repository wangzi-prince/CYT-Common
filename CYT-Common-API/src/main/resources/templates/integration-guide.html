从这里开始接入

1 · 领取调用身份

向管理员领取本系统独立 API Key，以及接入方可访问的网关地址。密钥放在业务后端环境变量 CYT_API_KEY。

2 · 选择接口并复制示例

下面只包含导出时已获授权的接口。按模块找到所需能力，填写真实业务参数；建议先验证一个只读接口。

3 · 核对返回结果

HTTP 检查 ok、meta.mock 和 data 中的 partial / errors。SDK 成功时直接返回 data；错误保留 trace_id。

本指南可离线阅读，无需管理后台账号。授权与配额在调用时实时检查；如需新增能力，请联系管理员。本包不包含 API Key 或上游凭据。

响应、重试与排错
HTTP 成功响应为 { ok, data, meta }，meta.mock=true 表示模拟结果。业务数据结构以对应接口为准，通用 SDK 直接返回 data。
401 / 403
检查调用方状态、API Key、接口授权和拒绝规则。
422 / 409
检查参数与幂等键；遇到冲突先核对原业务请求。
429 / 502 / 503
核对配额与上游状态，向管理员提供 error.trace_id。
分页结果以 page.has_more 和 next_cursor 判断完成；data.partial / errors 需要逐项处理。写请求不要盲目更换业务编号重试。
